# 择稿 iOS v0.1.0

当前构建：`0.1.0-txt-fold-r5`（2026-11-24）。package version仍为0.1.0。在r4基础上增量加入TXT材料、长气泡折叠和圆润无底板图标，保留回车偏好及r3回合处理。36项本机检查通过，尚待Fish Pocket真机验收。

目标仍为Fish Pocket App Store 1.2.1（120）、DSH 0.2.2-rc.4官方网页版。原输入框附件读取依赖已实测的非公开类方法，失效时保留输入，使用择稿工具→参考材料→添加TXT。
## 使用

在 Fish Pocket 的“探索 → 网页版”中使用；原生 SwiftUI 不运行插件页面。打开普通对话，点击输入框上方“择稿工具”，开启写作模式。

- 写作模式下，手机默认回车换行、点箭头发送。择稿工具→输入设置可切换Enter发送；Shift＋Enter交给宿主换行。网页不能可靠识别手机外接键盘，接入后请手动切换偏好。关闭写作模式后由宿主处理。
- 一个对话是一部作品。输入框写新段要求或讨论设定；自动模式对含糊话意先询问，也可显式切换讨论／续写。
- 已有稿件需点击确认，才按原文采用为作品开头或追加正文；不会自动替换现有稿。
- 候选气泡用 `< 当前版 / 总版 >` 浏览，点版本数字打开列表。浏览与采用分开，其他版本一直保留。
- 气泡图标从左到右为再生成、追加要求、手工编辑、复制、采用。改本段在气泡追加要求，新段要求放聊天栏。
- 手改保存新增版本；“保存并采用”在一次域更新中保存两项结果。编辑器还支持按连续自然段选择局部修改。
- 写作设定只保存作者确认的事实；讨论回复不自动成为设定或正文。
- 阅读模式只拼接已采用正文；右上角 Aa 打开字号、行距、深色与减少动态效果设置。
- 导出先准备固定快照，再点“分享文件”。TXT 为采用正文，JSON 保留候选、采用、设定、摘要和任务凭据。系统面板选择“存储到文件”。取消分享不会删除快照。
- JSON 恢复到新的空对话副本，不覆盖原作品。支持本版 formatVersion=2 和安卓0.0.8的正式 formatVersion=1 备份；旧摘要保留但不自动启用，需重新核对并另存。

第一次生成、讨论、摘要或局部修改会使用当前配置模型。导入原文和恢复备份不调用模型，但 rc.4 正常回合入口要求已选择一个模型路由。

## TXT材料与长气泡

写作模式下在宿主原输入框附上一个TXT，点发送后确认用途。支持UTF-8、1MiB以内且不超过80000字符，一次一份；非UTF-8、超限、图片或混合引用拒绝且保留输入，不静默截断。也可在参考材料页自行添加。

用途为参考材料、已有正文或混合文件选段。参考默认不计入正文、不自动确认待定设定；混合选段原文采用，其余作为参考，保留原文件全文。同名材料确认替换或保留两份；材料页可改变用途、启用停用、查看全文。保存材料走真实宿主无模型回合，需要宿主空闲且有已选模型路由；这是宿主入口要求，不代表本操作调用模型。

保存任务completed后才清理原输入框对应附件，不清除文字要求或后来新增附件。文字要求保留，用户确认材料后继续点箭头发送，不自动连带生成。读取/保存失败、未知结果时附件保留；不要重复导入，先重读核对。临时读取内容在页面内存中，只有后台保存确认才持久化。

材料写入既有作品域可选materials字段，旧schema1数据无需强制迁移，旧无材料备份可读。JSON备份包含材料与启用状态；TXT仍只导出已采用正文。已启用参考进入讨论/续写/改写上下文，剧情摘要仍只处理正文；上下文总预算40000字符，超限拒绝而非截断。新构建产生的材料数据不保证旧插件降级后仍能完整操作，勿在保存材料后直接降级。

作者要求超过8行、讨论超过12行默认收起；候选正文默认展开，支持向上箭头收起。按实际显示高度适应字号/行距；复制编辑采用导出使用全文。显示状态只在本次网页内保留。减少动态效果关闭过渡。

## 保存与上下文

权威数据使用 `ctx.storageDomain` 的 `zegao_ios` 域（schema 1、single 布局），按 sessionId 保存一条作品记录。写入 resolve 后才报告保存；更新在域串行队列内检查 expectedRevision，回执校验请求ID与内容指纹。不要手工改存储文件。

用户写作操作通过 `agent.followup()` 进入真实宿主回合。`agent/pre-step` 识别本插件消息，持久保存真实 user/message 锚点，完成独立模型调用后返回空消息决策。r3 用 Cordis 公开的 prepend 选项，将本插件处理器放到已注册的上下文中间件之前；自有任务不调用 next，普通输入仍调用 next，保留宿主处理。没有伪造 turn/start/turn/end，没有调用受限 appendPluginRecord。真实回合让已有作品离开宿主的空白复用状态。

模型请求从域内最新采用正文构造，带修订号和正文哈希清单；不重复叠加旧会话正文快照。改写时仅纳入目标段之前的采用正文，底稿只放一次。未采用候选、未保存草稿不进入正式正文。讨论也用同一条上下文构建路径，不产生候选段。普通聊天参考和插件讨论取最近12000字符；不会自动把 AI 建议确认为事实。

有效摘要仅在来源哈希一致时替代对应前文。前文改动后摘要不会悄悄沿用。总组装提示设40000 UTF-16字符保守上限，超过则拒绝并保留输入，不截断正文。它不是精确 token 计数，也不能保证每个模型的窗口都容得下；可在段落列表查看“下次续写上下文”。

任务先落盘后派发，同请求不重复调用。每任务独立停止信号，停止不清其他对话或普通聊天队列。只有完整 finish/stop 才形成完整候选，生成结果不自动采用。重启失联任务标中断，不自动补发；模型适配器自身重试和已发生消耗不由本插件承诺。

## 安装与构建

交付文件见 ../release-assets/，优先使用预构建 TGZ；手机安装包ZIP内封装同一TGZ和说明。不要直接以link:安装解压后的插件目录：手机实测该方式不会解析包内依赖，会缺zod。由正式插件管理机制以file: tarball方式安装TGZ，并按宿主提示正常重启。手机不需要编译；包没有 prepare/postinstall，不包含 native addon。依赖是精确 rc.4 的纯 JS 包。手机安装请使用本项目发布页单独提供的 TGZ；GitHub 自动生成的 Source code ZIP 不是手机安装包。本项目未提供 npm 安装地址。

电脑重建：Node >=24.9、pnpm；`pnpm install --frozen-lockfile --ignore-scripts`，`pnpm test`，`pnpm run pack:plugin`。测试命令自动构建，生成的 lib 可直接交付手机。本工程与安卓目录独立，src/legacy 只保留旧备份格式的解析代码。assets 中为授权使用的项目素材及压缩副本。

## 边界

- 本修复依赖已核对版本及注册顺序；若其他插件后来以 prepend 注册新的外层处理器，仍可能改写决策。没有宣称对任意插件热重载顺序作全局保证。更新后应正常重启，并由手机复核当前实际插件组合；不修改 DS Bot 源码。

- 普通发送接管仍是 DOM 捕获层；原生界面、其他插件的程序化发送可绕过。本版支持上述 TXT 导入路径；其他未支持的附件或引用需关闭写作模式后交由宿主处理，拒绝处理时保留原输入。
- 卡片使用官方槽位，工具/编辑/阅读浮层 portal 到 document.body。玻璃效果是网页模拟，非苹果原生 Liquid Glass。宿主原有页首由宿主控制，项目图标出现在插件工具中。
- 会话删除或分叉不隐式复制、删除独立域作品。失联作品仍可从“全部作品”JSON备份取回，在新空对话恢复；不是宿主会话导出自动携带的内容。
- 浏览器草稿只是尽力暂存，不能替代后台保存；私密模式、存储清理、跨设备可能丢失。切会话后未保存内容不进入另一作品。
- 首版无历史 iOS schema 升级路径；损坏或不支持的数据拒绝打开，不空初始化。未知持久结果需重新读取/重开核对，不能据页面文本假定成功。
